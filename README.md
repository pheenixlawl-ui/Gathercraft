# Gathercraft

**Gather. Route. Profit.**

A free gathering helper for **World of Warcraft: Forever** by pheenixlawl.

Gathercraft remembers every herb, ore and chest you gather, shows them on the
world map and minimap and guides you along the best live route between them,
using Blizzard's built-in waypoint.

## Features
- Automatic node recording (herbs, ores, chests) with object and spawn IDs
- Pins on the world map and minimap, dimmed while a node respawns
- Live farm route over all checked zones of a continent, re-planned while you move
- Zones window: choose continents, zones and materials per zone
- Skill data: which node gives skill points at which skill level
- Node sharing with other players (guild and friends trusted, public channel optional)
- Starter data from the beta for a quick start at launch

## Commands
`/gcr` or `/gathercraft` (the old `/fg` still works for now)

| Command | Description |
|---|---|
| `/gcr zones` | Choose zones and materials |
| `/gcr run [herb\|ore\|chest\|name]` | Start a farm run |
| `/gcr route` | Preview the route on the map |
| `/gcr skip` | Current node is empty, go to the next |
| `/gcr stop` | Stop the farm run |
| `/gcr pins` | Show/hide map pins |
| `/gcr skills` | Your gathering skills and what was learned |
| `/gcr sync` | Node sharing status and options |
| `/gcr options` | Options window |
| `/gcr help` | All commands |
